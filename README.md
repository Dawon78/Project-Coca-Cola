# 코카콜라 (Coca-Cola) 브랜드 사이트 클론

쌍용교육센터 KDT 과정 팀 프로젝트 · 팀 레츠기니 (5명)

코카콜라 웹사이트를 참고해 만든 브랜드 소개 사이트입니다.
서블릿 핸들러 방식으로 만든 프로젝트를 Spring MVC + MyBatis 구조로 리팩토링했습니다.

## 기술 스택
- **Back-end** : Java, Spring Framework (Spring MVC), MyBatis, Lombok
- **Front-end** : HTML5, CSS, JavaScript, JSP
- **Database** : Oracle
- **Server** : Apache Tomcat 9
- **Tools** : STS 3, SQL Developer, eXERD, GitHub, Notion

## 주요 기능
- 브랜드 목록 · 상세, 제품 소개
- Discover (브랜드 스토리, Coke&Meal, Originals, Opener, Creations, Coke Play)
- Sustainability, Our Company
- 회원가입 · 로그인 · 아이디/비밀번호 찾기

## 담당 역할 (김다원, 팀원)
- 팀원별 기능 통합 및 오류 수정, 일정 관리
- DB 구조 정리 (불필요한 컬럼 · 중복 데이터 정리)
- 브랜드 목록 · 상세 페이지, 아이디/비밀번호 찾기 구현

## 폴더 구조
- `cocacola/` : Spring MVC 프로젝트 소스
- `요구분석/`, `ERD 다이어그램/`, `eXERD/`, `테이블 생성 쿼리/` : 설계 문서
